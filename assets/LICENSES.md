## Rules

- Prefer CC0 (Poly Haven, ambientCG, Kenney, Quaternius, KayKit) for any downloaded asset, and add a row here when it's added.
- CC-BY or CC-BY-SA assets need an attribution plan (and share-alike review) before they ship.
- AI image-to-3D output may be used for one-off scenery props only (never ships or parts), with the tool named here.
