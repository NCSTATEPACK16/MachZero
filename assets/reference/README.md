# Concept reference (not shipped)

Drop Gemini concept images here, made from the prompts in `docs/v2/VEHICLE_CONCEPTS.md`:

- `ships/<id>/`: up to 4 JPEGs per chassis (≤ 500 KB each). Name your favourite `chosen.jpg`, and add `notes.md` to mix ideas.
- `parts/`: one image per slot (engine, booster, stabilizer, hull), showing the 4 tiers.

Claude only models a chassis that has a `chosen.jpg`. Log each batch in `assets/LICENSES.md`.
