# Concept reference (not shipped)

Drop Gemini concept images here:

- `ships/<id>/`: from `docs/v2/VEHICLE_CONCEPTS.md`. Up to 4 JPEGs per chassis (≤ 500 KB each). Name your favourite `chosen.jpg`, and add `notes.md` to mix ideas.
- `parts/`: one image per slot (engine, booster, stabilizer, hull), showing the 4 tiers.
- `worlds/<id>/`: from `docs/v2/WORLD_CONCEPTS.md`, for `tempest-spire`, `cinder-forge` and `abyss-line`. Up to 4 JPEGs per world (≤ 500 KB each). Name your favourite `chosen.jpg`, and add `notes.md` to mix ideas.

Claude only models a chassis, or builds a world's look, that has a `chosen.jpg`. Log each batch in `assets/LICENSES.md`.
